- # 蓝旭工作室春季考核后端题目评分标准（满分 100 分）

  ------

  #### **一、功能实现完整性（85 分）**

  1. **A. 插入数据到数据库（10 分）**
     - 创建 `exam_student` 表（字段正确、主键自增）。（3 分）
     - 使用 JDBC 实现插入逻辑，方法名为 `insertAStudent`。（4 分）
     - 类名正确（`ADao`），代码分层明确（Dao 层）。（3 分）
  2. **B. 导入学生数据（20 分）**
     - `service` 层实现 `saveFromCSV` 方法，调用 `dao` 层插入逻辑。（6 分）
     - 正确解析 CSV 文件并批量插入数据库。（8 分）
     - 异常处理（如文件不存在、格式错误）。（4 分）
     - 代码分层清晰（`BService` 和 `BDao`）。（2 分）
  3. **C. 查询“考核中”学生人数（5 分）**
     - 使用 `COUNT()` 函数查询数据库。（2 分）
     - 方法名 `countInProgress`，返回值正确。（2 分）
     - 类名和分层合理（如 `CDao`）。（1 分）
  4. **D. 接收并返回 JSON 数据（15 分）**
     - Servlet 处理 POST 请求，路径 `/exam/student`。（3 分）
     - 使用 FastJSON 解析请求体为 `StudentEntity` 对象。（5 分）
     - 设置 `id=20250510`，返回 JSON 响应，格式正确。（5 分）
     - 响应类型为 `application/json;charset=utf-8`。（2 分）
  5. **E. 更新学生状态（5 分）**
     - 方法 `updateStateToPassed` 使用 JDBC 更新状态。（3 分）
     - 根据姓名精准更新，返回布尔值表示成功与否。（2 分）
  6. **F. 查询符合条件的学生（20 分）**
     - 处理 POST 请求 `/query/student`，解析 `state` 参数，Service层、Dao层书写正确。（8 分）
     - 返回 JSON 格式（包含 `code`、`msg`、`data` 列表）。（6 分）
     - 错误处理（如数据库异常返回 `code=400`）。（4 分）
     - 数据表查询逻辑正确。（2 分）
  7. **G. 登录功能（10 分）**
     - 创建 `exam_user` 表（含 `id`、`username`、`password`）。（3 分）
     - 处理 `/user/login` 请求，验证用户名和密码。（4 分）
     - 返回 JSON 格式（成功 `code=200`，失败 `code=400`）。（2 分）
     - 密码安全处理（如加密存储）。（1 分）

  ------

  #### **二、代码规范性（5 分）**

  1. **分层架构（3 分）**
     - 严格遵循三层架构（Dao、Service、Controller），各层职责清晰。
  2. **命名规范（2 分）**
     - 类名（如 `ADao`、`BService`）、方法名（如 `saveFromCSV`）符合题目要求。

  ------

  #### **三、注释完整性（5 分）**

  1. **关键逻辑注释（3 分）**
     - 复杂逻辑（如 CSV 解析、JSON 转换）需有注释说明。
  2. **类与方法注释（2 分）**
     - 类功能说明、方法参数和返回值描述。

  ------

  #### **四、其他补充项（5 分）**

  1. **安全性（3 分）**
     - 使用 `PreparedStatement` 防止 SQL 注入（涉及 JDBC 的题目）。
  2. **异常处理（2 分）**
     - 捕获并处理异常（如数据库连接失败、JSON 解析异常）。

  ------

  #### **扣分项**

  - 未按要求命名类或方法（每处扣 1 分）。
  - 代码冗余或重复（每处扣 1 分）。
