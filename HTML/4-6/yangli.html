HTML语言简例

超文本标记语言 · 网页结构基石 | 直观示例涵盖常用标签、表单、代码展示及语义化结构

HTML（HyperText Markup Language）是构建网页内容和结构的标准语言。通过标签（elements）来标记文本、图片、链接、表单等元素， 浏览器解析后渲染出可视化页面。以下是一个轻量但完整的HTML实践范例，展示现代网页常用模块。

📌 常用标签一览

  • <h1> ~ <h6> — 标题层级，用于定义内容结构
  • <p> — 段落文本，承载说明性内容
  • <a> — 超链接，连接不同页面或资源
  • <img> — 嵌入图像，丰富视觉表现
  • <ul> / <ol> — 无序/有序列表，展示条目化信息
  • <div> 与 <span> — 布局容器与内联容器
  • <form> + <input> — 用户交互与数据收集
  • #语义化
  • #超文本
  • #跨平台
  • #可嵌套
  • #与CSS/JS协作

    • 📄 HTML 代码结构示意

    下面展示一份简洁的HTML文档基本结构，让你快速理解标签的层级关系：

    <!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>页面标题</title>
</head>
<body>
    <header>
        <h1>欢迎来到我的网页</h1>
    </header>
    <main>
        <p>这是一个使用HTML构建的内容区域。</p>
        <a href="https://developer.mozilla.org/zh-CN/">学习更多</a>
    </main>
    <footer>&copy; 2025 示例站点</footer>
</body>
</html>
    💡 提示：上述代码使用了字符转义（如 &lt; 表示 < ），保证在浏览器中作为文本显示。

    📝 文本格式与特殊符号

    HTML提供了丰富的文本语义标签：加粗(<strong>)，斜体(<em>)， 高亮(<mark>)，删除线(<del>) 以及 行内代码(<code>)。 此外，特殊字符实体如：&nbsp;（空格）、&copy;（版权符号©）、&lt; 和 &gt; 等。 

    常用转义示例：
&copy; → ©
&reg; → ®
&trade; → ™
&mdash; 表示长破折号
