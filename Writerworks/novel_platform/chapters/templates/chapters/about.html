📖 关于作家工厂

作家工厂 是一款专为小说创作者设计的轻量级写作管理工具。 无论你是业余爱好者还是专业作家，这里都能帮你高效组织作品、章节和大纲， 让创作过程更加流畅、有序。

本项目诞生于 2026 年 4 月，旨在提供一个简洁、优雅、功能完备的创作平台， 让写作者专注于内容本身，而无需被复杂的工具所困扰。

✨ 核心功能

📚 作品管理 创建、编辑、删除作品，支持封面图上传
📝 章节编辑 自动保存、实时预览，支持 Markdown 风格排版
🌳 大纲树 无限层级的大纲结构，轻松规划故事脉络
♻️ 回收站 软删除与恢复机制，误删也能轻松找回
🔍 智能搜索 快速定位作品与章节（预留功能）
📱 响应式设计 在电脑、平板、手机上皆可流畅使用

🛠 技术栈

Django 6.0 Python 3.12 SQLite HTML5 + CSS3 Flexbox / Grid JavaScript (Vanilla)
