# 连点器 (Auto Clicker) 设计与实现计划

## 1. 概述

设计并实现一个 Windows PC 端的自动连点器工具，打包为独立 `.exe` 文件，无需依赖 Python 环境即可运行。

## 2. 技术选型

| 组件       | 技术方案         | 说明                          |
| -------- | ------------ | --------------------------- |
| **语言**   | Python 3.10+ | 开发效率高，生态丰富                  |
| **GUI**  | tkinter      | Python 内置，无需额外安装，打包体积小      |
| **鼠标控制** | pyautogui    | 跨平台鼠标模拟点击                   |
| **全局热键** | pynput       | 监听全局键盘快捷键（后台运行）             |
| **打包工具** | PyInstaller  | 将 Python 脚本打包为独立的 `.exe` 文件 |

## 3. 功能设计

### 3.1 核心功能

* **点击类型**：单击、双击、连续点击

* **鼠标按键**：左键、中键、右键

* **点击间隔**：可自定义间隔时间（毫秒级），范围 1ms \~ 10000ms

* **点击次数**：自定义点击次数（1\~999999），或无限循环

* **点击位置**：

  * **当前鼠标位置**：点击时获取鼠标实时位置

  * **固定位置**：录制/手动输入 X, Y 坐标

* **启动/停止**：全局快捷键（默认 F6），点击「开始」按钮

### 3.2 辅助功能

* **状态显示**：运行状态（运行中/已停止）、已点击次数

* **窗口置顶**：可选项，让连点器窗口始终在最前

* **最小化到托盘**：运行时最小化至系统托盘

### 3.3 用户界面

* 简洁直观的窗口布局

* 参数设置区域

* 状态显示区域

* 开始/停止按钮

## 4. 项目结构

```
AutoClicker/
├── main.py              # 主程序入口，GUI 界面
├── clicker.py           # 点击逻辑核心模块
├── hotkey.py            # 全局热键监听模块
├── requirements.txt     # 依赖清单
├── build.spec           # PyInstaller 打包配置
└── README.md            # 使用说明（仅当用户要求时）
```

## 5. 实现步骤

### Step 1: 项目初始化

* 创建 `AutoClicker/` 项目目录

* 创建虚拟环境并安装依赖（pyautogui, pynput, pyinstaller）

* 编写 `requirements.txt`

### Step 2: 实现核心点击模块 (`clicker.py`)

* `Clicker` 类：管理点击线程

* 支持设置：点击类型、按键、间隔、次数、位置模式、固定坐标

* 点击循环逻辑：根据配置执行点击操作

* 线程安全：使用 `threading.Event` 控制启动/停止

### Step 3: 实现全局热键模块 (`hotkey.py`)

* 使用 `pynput.keyboard` 监听全局热键

* 默认热键 F6 切换 启动/停止

* 热键可自定义

### Step 4: 实现 GUI 界面 (`main.py`)

* 使用 `tkinter` 构建主窗口

* 参数配置区域（点击类型、按键、间隔、次数、位置）

* 状态显示区域（运行状态、已点击次数）

* 控制按钮（开始/停止）

* 窗口置顶选项

* 系统托盘功能（可选，使用 `pystray`）

### Step 5: 打包为 .exe

* 使用 PyInstaller 打包

* 配置 `--onefile` 生成单个 exe

* 配置 `--noconsole` 隐藏控制台窗口

* 添加图标文件

## 6. 依赖清单 (`requirements.txt`)

```
pyautogui>=0.9.54
pynput>=1.7.6
pyinstaller>=6.0.0
```

## 7. 打包命令

```bash
pyinstaller --onefile --noconsole --name "AutoClicker" --icon=icon.ico main.py
```

## 9. 注意事项

* 全局热键需要管理员权限（在某些系统上），必要时提示用户以管理员身份运行

* 点击间隔不宜过短（建议 >= 10ms），避免系统负担过重

* 打包后的 exe 文件大小约 10-20MB
