# 微信助手工具 - 设计方案

## 1. 项目概述

设计并实现一个微信助手工具，核心功能包括：

* **对接微信**: 通过企业微信 API / 微信个人号桥接（如 itchat/uiautomation）实现消息收发

* **整理会话**: 自动分类、标签化管理、关键词检索、重要消息收藏

* **规划日程**: 从聊天中提取日程事件，生成日历提醒，管理待办事项

## 2. 技术选型

| 模块     | 技术方案                                  | 说明               |
| ------ | ------------------------------------- | ---------------- |
| 语言     | Python 3.10+                          | 项目已有 Python 生态   |
| 微信对接   | 企业微信 API / itchat / PC 端 uiautomation | 根据实际需求选择         |
| Web 框架 | Django                                | 可选，提供管理界面        |
| 数据存储   | mysql                                 | 已有 Django ORM 经验 |
| 前端     |  / 简单 HTML+JS                         | 管理后台界面           |
| 任务调度   | APScheduler / Celery                  | 定时任务与提醒          |
| NLP    | 简单规则 + LLM API（可选）                    | 日程提取、语义分类        |

## 3. 功能模块设计

### 3.1 微信对接模块

* 消息监听与收发（文本、图片、文件、链接等）

* 联系人/群组管理

* 消息持久化存储

* 多账户支持（可选）

### 3.2 会话整理模块

* **自动分类**: 按联系人、群组、关键词自动归类

* **标签管理**: 用户自定义标签，为会话/消息打标签

* **全文搜索**: 支持关键词、日期、类型等多维度检索

* **重要消息**: 星标/收藏重要消息，便于后续查阅

* **会话归档**: 历史会话自动归档，按时间线查看

### 3.3 日程规划模块

* **日程提取**: 从聊天消息中自动识别时间、地点、事件（如"明天下午3点开会"）

* **日历管理**: 支持日/周/月视图，展示日程安排

* **待办事项**: 创建、完成、删除待办，支持优先级

* **提醒通知**: 定时提醒，支持桌面通知/邮件/微信推送

* **导出功能**: 日程导出为 iCal/CSV 格式

### 3.4 管理界面

* 消息记录查看与搜索

* 标签管理面板

* 日历视图

* 系统设置（通知偏好、API 配置等）

## 5. 数据模型设计

### 5.1 联系人表 (Contact)

| 字段          | 类型       | 说明        |
| ----------- | -------- | --------- |
| id          | Integer  | 主键        |
| wx\_id      | String   | 微信唯一 ID   |
| name        | String   | 昵称        |
| remark      | String   | 备注名       |
| type        | Enum     | 个人/群组/公众号 |
| avatar      | String   | 头像 URL    |
| created\_at | DateTime | 添加时间      |

### 5.2 消息表 (Message)

| 字段          | 类型       | 说明           |
| ----------- | -------- | ------------ |
| id          | Integer  | 主键           |
| msg\_id     | String   | 微信消息 ID      |
| contact\_id | FK       | 关联联系人        |
| type        | Enum     | 文本/图片/文件/链接等 |
| content     | Text     | 消息内容         |
| timestamp   | DateTime | 消息时间         |
| is\_starred | Boolean  | 是否星标         |
| tags        | M2M      | 关联标签         |

### 5.3 标签表 (Tag)

| 字段          | 类型       | 说明   |
| ----------- | -------- | ---- |
| id          | Integer  | 主键   |
| name        | String   | 标签名称 |
| color       | String   | 标签颜色 |
| created\_at | DateTime | 创建时间 |

### 5.4 日程表 (Schedule)

| 字段              | 类型       | 说明          |
| --------------- | -------- | ----------- |
| id              | Integer  | 主键          |
| title           | String   | 事件标题        |

| end\_time       | DateTime | 结束时间        |

## 7. 风险与注意事项

1. **微信接入风险**: 个人微信第三方接入存在封号风险，建议优先使用企业微信 API
2. **数据隐私**: 所有聊天数据本地存储，不上传第三方服务器
3. **合规性**: 遵守微信平台使用条款，不用于商业用途
4. **扩展性**: 模块化设计，便于后续增加 AI 分析、自动回复等功能
