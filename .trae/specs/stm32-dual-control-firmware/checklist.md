# 验证清单

- [x] STM32 固件项目基础框架已创建，1kHz 定时中断正常运行
- [x] MPU6050 驱动可正常读取加速度计和陀螺仪原始数据
- [x] 互补滤波/卡尔曼滤波可正确解算 Pitch 角与角速度
- [x] 串级 PID 控制器（直立环 + 速度环 + 转向环）输出正确 PWM
- [x] TB6612 电机驱动可正常控制左右 N20 电机正反转
- [x] 编码器可正确读取脉冲并换算为轮速和行驶距离
- [x] UART 通信波特率 ≥ 115200，收发帧格式正确
- [x] STM32 可正确解析树莓派下发的目标速度、表情控制、休眠/唤醒指令
- [x] STM32 可正确上报当前倾角、电池电压、电机转速、系统状态
- [x] 低电量检测阈值触发后自动减速并上报
- [x] 摔倒检测（倾角超阈值）触发后立即停机进入保护模式
- [x] 断联保护（1 秒无心跳）触发后自动减速至停止
- [x] RGB 指示灯/蜂鸣器根据系统状态正确输出（启动、平衡、报警、低电量）
- [x] 预留 I²C/GPIO 扩展接口可正常使用
