# Tasks

- [x] Task 1: 创建 STM32 固件项目基础框架
  - 使用 STM32CubeMX 初始化项目（选择 STM32F103C8T6 或 STM32F405RGT6）
  - 配置系统时钟（主频 72MHz+）、定时器、I²C、UART、PWM、GPIO 外设
  - 搭建 Keil MDK 或 STM32CubeIDE 工程目录结构
  - 实现 main.c 主循环框架与 1kHz 定时中断

- [x] Task 2: 实现 MPU6050 驱动与姿态解算
  - 实现 I²C 底层驱动（HAL 或 LL 库）
  - 实现 MPU6050 初始化与数据读取（加速度计 + 陀螺仪）
  - 实现互补滤波或卡尔曼滤波算法，解算 Pitch 角与角速度
  - 在 1kHz 中断中完成数据采集与解算

- [x] Task 3: 实现串级 PID 控制器与电机 PWM 输出
  - 实现直立环 PID 控制器
  - 实现速度环 PID 控制器（需编码器反馈）
  - 实现转向环 PID 控制器（可选）
  - 配置定时器 PWM 输出，驱动 TB6612 的 A/B 通道
  - 配置方向控制 GPIO

- [x] Task 4: 实现编码器读取与轮速换算
  - 配置定时器编码器模式（Encoder Mode）读取正交信号
  - 实现脉冲计数 → 轮速（rpm）换算
  - 实现行驶距离累计计算
  - 将轮速数据提供给速度环 PID

- [x] Task 5: 实现 UART 通信协议
  - 配置 UART 外设（波特率 115200+，DMA 或中断模式）
  - 定义通信协议帧格式（帧头、数据、校验、帧尾）
  - 实现指令接收解析模块（目标速度、表情控制、休眠/唤醒）
  - 实现数据上报模块（倾角、电压、转速、系统状态）
  - 实现心跳检测与断联保护（1 秒超时）

- [x] Task 6: 实现电源管理与安全逻辑
  - 配置 ADC 读取锂电池分压后的电压值
  - 实现低电量检测与减速逻辑
  - 实现摔倒检测（倾角超阈值 → 立即停机）
  - 实现断联保护（1 秒无心跳 → 减速停止）

- [x] Task 7: 实现辅助功能与扩展接口
  - 实现 RGB 指示灯驱动（GPIO 或 PWM 控制）
  - 实现蜂鸣器驱动
  - 定义状态指示映射（启动=蓝色、平衡=绿色、报警=红色、低电量=黄色闪烁）
  - 预留 I²C 或 GPIO 扩展接口（舵机控制等）
