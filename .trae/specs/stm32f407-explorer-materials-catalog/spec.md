# 正点原子探索者STM32F407开发板V3资料盘(A盘) 资料整理 Spec

## Why
用户拥有正点原子探索者STM32F407开发板V3的资料盘(A盘)，需要对其中的学习资料、硬件信息、软件资料等进行系统化的消化整理，并生成一份结构化的资料表，方便后续查阅和使用。

## What Changes
- 遍历并列出资料盘(A盘)根目录下5大分类的完整目录结构
- 整理每个分类下的子目录、文件类型、用途说明
- 在同目录下生成一份结构化的资料表（资料表.md），包含：分类、子目录/文件名、文件类型、用途/说明
- 资料表需要覆盖所有主要文件和目录，忽略readme.txt等非核心文件

## Impact
- Affected specs: 无（新增规格）
- Affected code: 无代码变更，仅新增文档
- 输出文件: `D:\A_Mycomputer\下载\baidu\【正点原子】探索者STM32F407开发板V3 资料盘(A盘)\资料表.md`

## ADDED Requirements
### Requirement: 资料表生成
系统应在资料盘(A盘)根目录下生成一份结构化的资料表 Markdown 文件，涵盖所有5大分类下的核心资料。

#### Scenario: 资料表覆盖所有分类
- **WHEN** 资料表生成完成
- **THEN** 资料表应包含以下5大分类的完整条目：
  - 1，入门资料（含PDF教程、验收工程）
  - 2，视频教程
  - 3，原理图（含PDF原理图、IO引脚分配表）
  - 4，程序源码（含寄存器版本、HAL库版本、扩展例程、启动文件）
  - 5，SD卡根目录文件（含PICTURE、SYSTEM资源）

#### Scenario: 资料表格式清晰
- **WHEN** 用户打开资料表
- **THEN** 资料表应以表格形式呈现，包含：序号、分类、文件名/目录名、格式/类型、用途说明

#### Scenario: 资料表内容准确
- **WHEN** 资料表反映实际目录结构
- **THEN** 所有条目应与实际文件系统中的文件/目录一一对应
