# STM32 自平衡小车 — 零基础小白完整规划书 Spec

## Why
零基础用户希望从0开始制作一台STM32自平衡小车，但缺乏电子工程和嵌入式开发知识。现有技术文档过于专业，缺少硬件选型对比、引脚接线图、编译烧录步骤等面向小白的实操内容。需要一份极细致的规划书，覆盖从买材料到小车跑起来的全流程。

## What Changes
- 新增一份 `BUILD_GUIDE.md` 完整规划书文档，放置在 `firmware/` 目录下
- 内容覆盖：材料清单（含品牌型号尺寸、价格区间、替代方案）、硬件接线（逐引脚说明）、软件环境搭建（STM32CubeIDE 安装→项目导入→编译→烧录）、代码功能与文件对应关系说明、调试方法、常见问题排查、后续升级路径

## Impact
- Affected specs: 新增规划书文档
- Affected code: 不修改任何现有代码，仅新增 `firmware/BUILD_GUIDE.md`

## ADDED Requirements

### Requirement: 材料清单（含选型对比）
The system SHALL 提供一份完整材料清单，每一项包含：
- **推荐型号**：具体品牌、型号、尺寸、关键参数
- **参考价格**：单价和总价预估
- **购买渠道**：淘宝/拼多多/闲鱼等常见渠道
- **替代方案**：至少1种下位替代（更便宜/更易买）
- **升级方案**：更高性能的可替换选项

#### 材料清单覆盖范围
- **MCU 主控板**：STM32F103C8T6 最小系统板（蓝色/黑色板），含选型理由
- **姿态传感器**：MPU6050 六轴模块（GY-521），含替代 JY61/MPU9250
- **电机驱动**：TB6612FNG 双路电机驱动模块，含替代 L298N/DRV8833
- **电机**：N20 微型直流减速电机（带编码器），含减速比选择建议
- **车轮**：65mm 橡胶轮 + 联轴器
- **电池**：3S/2S 锂电池，含容量和放电倍率选择
- **底盘**：亚克力/3D打印/铝合金车架
- **通信模块**：HC-05/HC-06 蓝牙模块（可选，供调试用）
- **其他**：杜邦线、面包板、排针、降压模块、开关、RGB LED、蜂鸣器、电阻电容等

### Requirement: 硬件接线指导（逐引脚）
The system SHALL 提供逐引脚的接线说明，包含：
- STM32 最小系统板引脚图标注
- 每个模块与 STM32 的引脚对应表（STM32 引脚 → 模块引脚）
- 接线图示（文字描述 + 伪接线图）
- 电源分配方案（各模块供电电压、电流需求、共地说明）
- 注意事项（电平匹配、上拉电阻、滤波电容等）

#### 接线覆盖范围
- MPU6050 → I2C1（PB6-SCL, PB7-SDA）
- TB6612 → 左右电机 PWM + 方向 IO（PA0/PA1 等）
- 编码器 → TIM2/TIM3 编码器模式引脚
- 蓝牙/USART1 → PA9(TX), PA10(RX)
- RGB LED → PC0/PC1/PC2
- 蜂鸣器 → PC4
- 电池 → 降压模块 → STM32 5V/VIN
- 电池 → TB6612 VM 供电

### Requirement: 软件环境搭建与烧录步骤
The system SHALL 提供从零开始搭建开发环境的详细步骤：
- **STM32CubeIDE 下载与安装**（含版本选择、安装注意事项）
- **新建/导入项目**：如何用 CubeMX 配置外设并生成代码，或导入本仓库已有项目
- **编译**：点击哪个按钮，如何看编译输出，常见编译错误解决
- **烧录**：ST-Link 下载器接线（SWDIO/SWCLK/GND/3.3V），Keil 或 CubeIDE 烧录设置
- **串口调试助手使用**：PuTTY/SSCOM 查看输出数据
- **首次运行验证**：如何确认程序正在运行（LED 闪烁、串口输出）

### Requirement: 代码结构与功能对照
The system SHALL 以表格形式说明每个文件的功能和修改方法：
- 文件树概览
- 每个 `.c/.h` 文件的功能说明
- 关键参数在哪里修改（PID 系数、引脚定义、控制频率等）
- 主循环和中断的执行流程说明

### Requirement: 调试方法与常见问题
The system SHALL 提供调试指南：
- 如何用串口观察 MPU6050 数据
- PID 参数调节方法（先调 P → 再加 D → 最后加 I）
- 常见问题排查表（电机不转、倾角数据异常、通信失败等）
- 安全注意事项（电池防反接、避免短路、首次调试建议绑绳）

### Requirement: 后续升级路径
The system SHALL 提供分级升级建议：
- **初级**：蓝牙遥控、WiFi 控制（ESP8266）
- **中级**：加入树莓派上位机视觉识别、路径规划
- **高级**：更换更高性能主控（STM32F405/F407）、增加舵机云台、加入 ROS
